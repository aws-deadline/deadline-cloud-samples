# POV-Ray 3.7 AWS Deadline Cloud Job Template

This OpenJD job template enables POV-Ray 3.7 raytracing rendering on AWS Deadline Cloud using conda package management.

## Overview

POV-Ray (Persistence of Vision Raytracer) is a high-quality, free tool for creating three-dimensional graphics. This template renders POV-Ray scenes in AWS Deadline Cloud with full parameter control.


## Usage

This job must be submitted to a queue that supports Conda with a CondaChannels parameter.
POV-Ray is available in conda-forge. This template overrides the CondaChannels to enable CondaForge.

## Features

- **Resolution and Quality Settings**: Render quality control (0-11 scale)
- **Conda Package Management**: Installation of POV-Ray via conda-forge

## Template Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `InputScene` | PATH | `sample/sample.pov` | Input POV-Ray scene file (.pov) |
| `OutputDirectory` | PATH | `output` | Output directory for rendered images |
| `OutputFilename` | STRING | `render` | Output filename (without extension) |
| `ImageWidth` | INT | 800 | Image width in pixels (100-4096) |
| `ImageHeight` | INT | 600 | Image height in pixels (100-4096) |
| `Quality` | INT | 9 | Render quality (0-11, higher is better) |
| `Antialiasing` | FLOAT | 0.3 | Antialiasing threshold (0.0-1.0) |
| `CondaPackages` | STRING | `povray` | Conda packages to install |

## POV-Ray Command Structure

The template executes POV-Ray with the following command structure:
```bash
povray +I{input_scene} +O{output_file} +W{width} +H{height} +FN +Q{quality} +A{antialiasing} +V -D
```

### Command Line Options Used:
- `+I`: Input scene file
- `+O`: Output file
- `+W`: Image width
- `+H`: Image height  
- `+FN`: PNG format output
- `+Q`: Quality level (0-11)
- `+A`: Antialiasing threshold
- `+V`: Verbose output
- `-D`: No display (render only)
